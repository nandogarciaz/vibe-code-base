## Sobre o repositório

Este repositório reúne o conteúdo usado na aula **"Vibe Coding — Organize seu projeto antes de começar a desenvolver"**.

A ideia central da aula: antes de pedir para a IA escrever qualquer linha de código, vale organizar o projeto. Com contexto, estrutura e regras bem definidas, a IA entrega resultados mais consistentes e você evita retrabalho.

Aqui você encontra os arquivos mostrados no vídeo, para acompanhar a aula e reaproveitar no seu próprio projeto.

## Como usar

1. Assista à aula para entender o passo a passo.
2. Clone o repositório:
   ```bash
   git clone https://github.com/nandogarciaz/vibe-code-base.git
   ```
3. Copie os arquivos para o seu projeto e adapte ao seu contexto.
4. Só então comece a desenvolver com a sua ferramenta de IA.

## Para quem é

Para quem está construindo soluções com IA e quer sair do "prompt solto" para um processo organizado, do planejamento à entrega.
