# PRD — [Nome do produto/entrega]

## Visão
Descreva em 2-3 frases o problema que este produto/entrega resolve e para
quem.

## Objetivo de negócio
Qual resultado mensurável isso deve gerar (ex: reduzir tempo de checkout
em 30%, aumentar retenção, etc).

## Personas / usuários
Quem usa isso e em que contexto.

## Escopo macro
Lista de alto nível das grandes funcionalidades que compõem essa entrega.
Cada uma delas, quando detalhada, vira um spec em `docs/specs/`.

- Feature A — [uma linha de descrição]
- Feature B — [uma linha de descrição]

## Fora de escopo
O que explicitamente não faz parte desta entrega, para evitar ambiguidade.

## Métricas de sucesso
Como saberemos que isso funcionou depois de lançado.
